Mac & Desktop

Install the web app

1. On your Mac (connected to your Tailscale network), open your MKSAP server URL in your browser.
2. Install it as a desktop app:
  • Safari: File → Add to Dock…
  • Chrome / Edge: click the Install icon in the address bar.
3. Launch it from the Dock — full offline support and progress syncs with your iPhone automatically.
